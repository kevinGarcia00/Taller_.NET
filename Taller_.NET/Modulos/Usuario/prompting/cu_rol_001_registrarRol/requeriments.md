# Requerimiento: Alta rol

## Descripción General
Como usuario con rol en el sistema SolarUY, quiero poder crear un nuevo rol en la plataforma.

## Criterios de Aceptación
1. Formulario de ingreso de un nuevo rol: El sistema debe permitir el ingreso de los siguientes datos obligatorios:
    - Nombre (Obligatorio).
    - Gestion usuarios (Boolean) (Obligatorio).
    - Gestion del modulo parques (Boolean) (Obligatorio).
    - Capacidad de mantenimiento (Boolean) (Obligatorio).

## Reglas de Negocio
- No pueden existir dos roles con el mismo nombre.
